# Appendices

## Appendix A — Reproducing the Experiments

All commands are run from the repository root. See `docs/EXPERIMENTS.md` for
details.

```bash
# broker
/opt/homebrew/sbin/mosquitto -c configs/mosquitto.conf

# baseline model (Section 5.1.2)
.venv/bin/python scripts/train_audio_cnn.py

# YOLO label check (Section 5.1.1)
.venv/bin/python scripts/fetch_vggsound_thumbnails.py
.venv/bin/python scripts/measure_label_noise.py

# strategies A, B and the C learning-rate sweep (Sections 5.2-5.4)
.venv/bin/python scripts/run_strategy.py --strategy a \
    --max-samples 5000 --stream-rate-ms 500 --num-rounds 10 \
    --buffer-size 500 --train-trigger-samples 1000
.venv/bin/python scripts/run_strategy.py --strategy b \
    --max-samples 5000 --num-rounds 10
for lr in 1e-3 5e-4 1e-4 5e-5; do
  .venv/bin/python scripts/run_strategy.py --strategy c \
    --max-samples 5000 --num-rounds 10 --epochs-per-round 1 \
    --local-lr $lr
done

# fusion, run 1 (Section 5.7)
.venv/bin/python scripts/spike_vggsound_pairs.py --per-class 200 \
    --max-attempts-per-class 600
.venv/bin/python scripts/prepare_vggsound_pairs.py
.venv/bin/python scripts/train_fusion.py --model all
.venv/bin/python scripts/train_fusion.py --model fusion \
    --modality-dropout 0.3
.venv/bin/python scripts/train_fusion.py --model fusion \
    --modality-dropout 0.5
.venv/bin/python scripts/train_fusion.py --model fusion \
    --modality-dropout 0.5 --audio-warmstart
.venv/bin/python scripts/eval_fusion_blackout.py

# fusion, run 2 (Section 5.7)
.venv/bin/python scripts/train_fusion.py --model fusion --epochs 25 \
    --es-patience 25
.venv/bin/python scripts/train_fusion.py --model fusion \
    --modality-dropout 0.5 --epochs 25 --es-patience 25
.venv/bin/python scripts/train_fusion.py --model fusion \
    --modality-dropout 0.5 --epochs 25 --es-patience 25 \
    --audio-warmstart
.venv/bin/python scripts/eval_fusion_blackout.py
.venv/bin/python scripts/probe_fusion_audio_use.py

# FB and FC (Section 5.8)
.venv/bin/python scripts/prepare_fusion_fv.py
.venv/bin/python scripts/run_strategy.py --strategy fb \
    --buffer-size 250 --train-trigger-samples 500 --num-rounds 6 \
    --stream-rate-ms 50
.venv/bin/python scripts/run_strategy.py --strategy fc --num-rounds 10 \
    --local-lr 1e-4

# live data: training-settings sweep (Section 5.6.3) and latency (Section 5.9)
.venv/bin/python scripts/sweep_live_training.py
.venv/bin/python scripts/measure_inference_latency.py

# all result charts of Chapter 5
.venv/bin/python scripts/make_thesis_figures.py
```

The live Raspberry Pi runs follow the step-by-step runbook in
`docs/PRESENTATION.md`. Each strategy run writes `server.json`, `client_A.json`, `client_B.json`, logs and an
`invocation.txt` with the exact command to `results/strategy_<x>/run_<time>/`.
